Create a new responsive “Our Branches” section for the Bangalore Islahi Trust website using the data from `@madrasa_branches_info.md`.

The website already has a modern UI, so this section should feel:

* Professional
* Premium
* Clean
* Islamic-academic themed
* Elegant and trustworthy
* Suitable for an educational and religious institution

Avoid flashy startup-style designs. Use a balanced professional aesthetic with subtle Islamic design influence.

## Section Requirements

### Section Title

Use:

* “Our Madrasa Branches”
* Subtitle: “Explore our branches across Bengaluru and online learning programs.”

---

## Card Design Requirements

Create modern clickable cards for each madrasa branch.

Each card should contain:

* Branch name
* Location
* Short timing info
* Classes available
* Small highlight/speciality
* Contact number
* “View Details” CTA/button/icon

Cards should:

* Have hover animation
* Soft shadows
* Rounded corners
* Glassmorphism or premium minimal style
* Professional typography
* Excellent spacing
* Responsive layout
* Smooth transitions

Do NOT overcrowd cards with too much text.

---

## Interaction Requirement

When a user clicks a card:

* Open a detailed modal / drawer / expandable panel
  OR
* Navigate to a detailed branch page

The detailed view should show:

* Full branch details
* Timings
* Address
* Full speciality list
* Contact info
* Optional QR placeholder
* Optional map placeholder

---

## Design Guidelines

### Color Palette

Use colors suitable for an Islamic educational trust:

* Deep emerald
* Teal

* Dark slate text

Use elegant readable fonts:
